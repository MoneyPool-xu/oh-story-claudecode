# 角色与剧情三章校准

这是每完成 3 章生成一次的**派生诊断视图**，不是第二份剧情状态。唯一权威仍是 `追踪/_tracking-state.json`；正文事实仍由逐章事务写入并确定性派生。

建议输出到 `报告/连续性/角色与剧情台账.md`，页首写明 `generated_from_state_revision`、覆盖章节与 `CURRENT / STALE`。正文或追踪修订后版本不匹配即作废，不允许反向覆盖追踪状态。

## 校准项目

- **冲突指纹**：近三章的冲突触发、对手手段、主角解法、公开结果；与历史同类记录比较，区分递进复用和换皮重复。
- **已兑现战果**：哪些羞辱、反证、打脸、关系表态已经结算；再次使用必须产生更高代价、新信息或新关系结果。
- **主角底牌**：当前可用、受限、暴露、消耗的能力/资源；不得把“作者计划”误记为人物已经掌握。
- **核心角色契约**：目标、能力边界、不可无因跨越的性格底线，以及本阶段关系/信任状态。
- **下一批风险**：只列会影响未来三章的重复、降智、能力遗忘或关系倒退，并附章节/追踪证据。

下一章仍完整读取紧凑的 `追踪/上下文.md`。只有涉及匹配冲突或核心角色时，才注入本台账的相关小节；禁止把不断增长的整份台账作为 Strong Context 塞给 Writer。
