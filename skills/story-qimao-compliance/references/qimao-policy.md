# 七猫投稿签约规范执行摘要

> 本文件综合七猫平台公开规则和四次退稿实战教训整理，不是平台规则原文。平台规则可能更新；需要核对最新规则时查验官方页面。

## 适用范围

覆盖投稿正文（通常前三章）、简介、大纲摘要和投稿附言。

## 平台硬红线（与番茄一致）

### 1. 法律法规和政策风险

- 违反法律法规，危害国家统一、安全、尊严和利益。
- 恐怖主义、极端主义，民族仇恨或歧视。
- 宗教狂热、邪教、现实封建迷信宣传。
- 淫秽色情、赌博、吸毒、暴力恐怖渲染、犯罪教学。
- 侵害未成年人权益。
- 隐私泄露、侮辱诽谤、造谣侵权。

虚构灵异、反派犯罪、战斗和角色冲突可以作为剧情元素，但不得变成现实可复现教程或模仿诱导。

### 2. 不当盈利与平台秩序

- 无关广告、引流、诈骗。
- 传授违规经验、利用平台漏洞。

### 3. 批量无意义内容

- 重复或高度相似内容。
- 符号、乱码、无序文字填充。
- 百科、新闻、教材拼凑。

## 七猫女频签约标准（四次退稿复盘）

### 赛道匹配（退稿首因）

| 赛道 | 七猫女频签约率 | 备注 |
|------|-------------|------|
| 现言总裁 | 高 | 七猫女频第一赛道 |
| 古言宅斗 | 高 | 第二赛道，需真正写内宅博弈 |
| 重生/穿越 | 高 | 通常叠加以上赛道 |
| 甜宠 | 中高 | 需要爽点支撑，纯甜不够 |
| 玄学/系统 | 中 | 需叠加宅斗或总裁 |
| 权谋天下 | 极低 | 四次被拒全踩此坑 |
| 军事/女将军 | 极低 | 七猫女频零上榜 |
| 朝堂布局 | 极低 | 即使包装成宅斗也容易滑回 |

**赛道红线：**
- 标签不选"权谋天下"。
- 女主不做女将军、女丞相、女帝。
- 冲突解决通过后宅手段（医毒、经商、管家、联姻），不通过朝堂布局。
- 涉及家族兴衰时通过内宅路径实现，不写上朝议事。

### 黄金三章标准

编辑看前三章（有时只看前一章）决定是否签约。

**节奏硬指标：**
- 第一章：500字内建立核心冲突，章尾金手指激活信号。
- 第二章：金手指首次实战展示，女主第一次反击。
- 第三章：首次打脸完成，CP有实质互动，三重悬念建立。
- 单次心理描写不超500字。
- 单次背景交代不超300字。
- 对话要短（单句不超30字为主），动作要快，打脸要狠。
- 每章一个独立冲突，每三章一个小高潮。

**金手指可见性（退稿高频点）：**
- 金手指必须"看得见"——有具象的技能释放、物品变化、感官冲击。
- 权谋布局、军事策略等抽象操作读者感受不到"爽"。
- 前三章中必须让编辑一眼看到金手指的"可视化爽点"。
- 好的例子：先祖上身、技能释放、当场辨毒、当场打脸。
- 坏的例子：心中有了计较、暗中布局、等待时机。

**CP前置（退稿高频点）：**
- 男主必须在前10章正式出场。
- 前三章必须有男主与女主的实质性互动（不是远远看一眼）。
- 互动要产生"他为什么帮她""他知道什么"的好奇心。
- 双向吸引信号至少有一个方向可见。

### 简介标准

- 第一句必须抛出最大悬念或最强卖点。
- 不用"她重生了"这种平淡开头。
- 书名必须包含核心卖点关键词。
- 简介中要体现金手指的具象用法。
- CP互动要有至少一组有张力的对话展示。

### 投稿附言标准

- 如果是多次投稿，主动说明调整方向。
- 展示对平台赛道的理解。
- 说明本书的差异化卖点。
- 不要自夸，用事实说话。

## 恶意水文判定

与番茄一致，加上七猫特有的节奏要求：

- 大量低质、逻辑不连贯内容。
- 节奏异常慢（前三章还没出现冲突/金手指/CP）。
- 连续超过500字的心理描写或内心独白。
- 连续超过300字的环境/背景描写。
- 流水账叙事（无冲突、无选择、无结果的事件罗列）。
- 人物单薄、出场突兀、前后不一致。

章节质量最低闭环：明确目标 → 人物选择和行动 → 现场变化 → 结果/代价/新问题。

## 题材专项边界

### 古言宅斗

- 核心是"内宅博弈"：嫡庶之争、婆媳矛盾、妯娌倾轧、管家夺权。
- 复仇手段是后宅路径：查账、辨毒、经商、管家、联姻、收买下人。
- 不要写着写着滑向朝堂权谋。
- 允许涉及家族兴衰，但通过后宅手段实现。

### 重生文

- 重生必须在第一章完成。
- 前世记忆通过碎片闪回展示，不要整段回忆录。
- 重生优势要通过行动体现，不要通过大段内心独白解释。

### 玄学/占卜/金手指

- 占卜/玄学作为金手指时，结果必须模糊（给碎片不给答案）。
- 代价体系要明确且递增。
- 占卜→行动→验证的循环要快速可见。

## 发布结论边界

- 签约取决于编辑主观判断，本检查只降低已知风险。
- `PASS` 只表示受检范围内未发现本 skill 定义的风险，不保证签约。
- 没有编辑具体拒稿理由时，不断言某一段就是命中原因。
