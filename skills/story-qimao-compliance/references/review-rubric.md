# 七猫投稿前审查量表

## 证据分级

| 等级 | 含义 | 处置 |
|---|---|---|
| BLOCK | 明确红线或赛道严重偏移 | 修订前不得投稿 |
| FIX | 高概率影响签约或编辑印象 | 修改后复查 |
| REVIEW | 依赖编辑偏好或上下文 | 人工确认并记录边界 |
| PASS | 本次范围未发现已定义风险 | 不等于编辑保证签约 |

## 审查顺序

1. 确认受检文件（前三章正文、简介、大纲、投稿附言）和是否授权修改。
2. 运行静态预检，记录确定性信号。
3. 人工检查平台硬红线。
4. **赛道匹配检查**（七猫特有，最重要）。
5. **黄金三章节奏检查**（逐章）。
6. **金手指可见性和CP前置检查**。
7. 低质与水文检查。
8. 简介和投稿附言检查。
9. 运行项目已有的 AI 句式和标点脚本。
10. 综合判断：如果你是七猫编辑，会签吗？

## 人工检查清单

### 平台硬红线

- [ ] 无违法政策、恐怖极端、民族宗教和封建迷信宣传风险。
- [ ] 无淫秽色情、赌博吸毒、犯罪教学和暴力恐怖渲染。
- [ ] 无未成年人不当内容。
- [ ] 无隐私泄露、侮辱诽谤、侵权。
- [ ] 无广告引流、诈骗、绕审教学。

### 赛道匹配（四次退稿首因）

- [ ] 题材标签在七猫女频验证赛道内（宅斗/总裁/重生/甜宠）。
- [ ] 未出现权谋/军事/女将军/女帝/朝堂布局元素。
- [ ] 宅斗在写"内宅博弈"，未滑向朝堂。
- [ ] 冲突解决通过后宅手段（医毒/经商/管家/联姻）。
- [ ] 标签未选"权谋天下"。

### 黄金三章节奏

**第一章：**
- [ ] 500字内建立核心冲突或重大异常。
- [ ] 重生/穿越在本章完成。
- [ ] 章尾有金手指激活信号或明确钩子。
- [ ] 无超500字连续心理描写。
- [ ] 无超300字连续背景交代。

**第二章：**
- [ ] 金手指有"看得见"的首次实战展示。
- [ ] 女主有第一次主动反击。
- [ ] 新信息或新能力推进剧情。

**第三章：**
- [ ] 首次打脸完成，读者获得爽感释放。
- [ ] CP有实质互动（不是远远看一眼）。
- [ ] 章尾建立三重悬念。
- [ ] 男主有令人印象深刻的出场或互动。

**整体：**
- [ ] 每章有独立冲突和小高潮。
- [ ] 情绪曲线有起伏，不是全程高压或全程平淡。
- [ ] 对标爆款前10章节奏（每章一冲突，每3章一小高潮）。

### 金手指可见性

- [ ] 金手指有具象技能释放（不是抽象分析/心中有了计较）。
- [ ] 使用后产生即时可见效果。
- [ ] 读者能一眼理解"这个金手指怎么用、能干什么"。
- [ ] 前三章至少两次金手指展示。

### CP前置

- [ ] 男主在前三章出场。
- [ ] 有与女主的实质互动（对话/动作/情感信号）。
- [ ] 产生"他为什么帮她"或"他知道什么"的好奇心。
- [ ] 至少一个方向有吸引信号。

### 简介检查

- [ ] 第一句抛出最大悬念或最强卖点。
- [ ] 不用"她重生了"等平淡开头。
- [ ] 体现金手指的具象用法。
- [ ] 有至少一组CP张力对话。
- [ ] 书名包含核心卖点关键词。

### 投稿附言检查

- [ ] 多次投稿时说明调整方向。
- [ ] 展示对平台赛道的理解。
- [ ] 说明差异化卖点。

### 章节质量

- [ ] 每章有明确目标、关键行动、可见结果和翻页推动力。
- [ ] 转折有来源，人物出场有铺垫。
- [ ] 无重复段落、百科拼贴、符号乱码、流程日志。
- [ ] 章尾落在具体动作、物件或悬念，不做升华总结。
