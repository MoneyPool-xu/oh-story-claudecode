# 七猫签约审稿风险诊断

仅在目标平台明确为七猫时使用。结论是编辑与读者风险判断，不承诺过审、签约或推荐；不以固定字数、爆点数量和指定桥段代替文本证据。

## 第一层：编辑第一眼

- 书名、简介、标签给出的核心卖点是否具体、有差异，并在前三章可感知。
- 开篇是否先建立人物问题，而非先交代大量世界观。
- 简介承诺与正文体验是否一致；若不一致，标明是物料问题还是正文兑现问题。

## 第二层：阅读动力

- 主角是否主动定义目标、作出选择并承担后果。
- 冲突是否改变身份、关系、资源、风险、目标或行动方向。
- 至少一次兑现是否具备“压力 → 主动行为 → 可见结果 → 后果”，并归还给承压和选择的人。
- 当前章末是否留下具体下一问，而非抽象预告。
- 慢热段是否保持 Attention Continuity：有明确等待，并持续给证据、部分支付或关系变化。
- 反派是否拥有可信资源、制度、关系或信息优势，而非靠全员降智续命。

## 第三层：正文质量

- POV 越界、人物降智、因果断层和数据连续性。
- 重复解释、无效心理、无功能微动作、套话、镜像金句和段尾总结。
- 新人物、新关系、新设定和时间线是否超过当前行动所需，造成认知负担。
- 是否为了“无线节奏”写成短剧台词、机械打脸、集体脸色变化或等距爆点。

## 诊断输出

七项指标分别给 `PASS / RISK / BLOCK`、正文证据和最小修复方向：Promise Visibility、Protagonist Agency、Conflict Consequence、Payoff Quality、Cognitive Load、Antagonist Credibility、Prose Friction。不要汇总成一个分数，也不要为了全绿破坏人物因果。拒审反馈中的“设定普通、开篇弱、爽点不足、情节生硬、文笔待提升”必须落到上述具体证据，不做字面式机械修复。
