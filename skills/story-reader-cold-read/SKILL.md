# story-reader-cold-read：读者盲读审查

复原“正文实际让读者经历了什么”，不要用作者资料替正文补洞。第一遍保持只读以保护盲读有效性；第二遍确认正文缺失、破坏性误导、投放失衡或弃读阻力后，默认直接修订并重新冷读，不等待用户逐项确认。

## 锁定输入与顺序

1. 确认目标正文、章节顺序和审查范围。
2. 第一遍只读取读者在该阅读时点可见的材料：书名、简介、正文、必要的公开章名。
3. 第一遍不得读取大纲、设定、人物卡、伏笔表、追踪文件、拆文报告、作者解释或旧审稿结论；若已在本轮看过，明确说明盲读受污染，改做“模拟冷读”。
4. 按发布顺序连续阅读，不先搜索答案，不倒回作者资料补解释。
5. 第二遍获得授权后才读取作者意图材料，定位“作者知道但正文没写”“信息出现过早或过晚”等偏差。

独立稿件不自动绑定当前活跃 story 项目。需要具体记录格式时读取 `references/cold-read-ledger.md`。

## 第一遍：只记录读者体验

按场景或章节记录：

- **读者已知**：正文已经明确提供且普通读者能记住的信息。
- **读者推测**：能够由文本合理推出但尚未证实的理解。
- **关键疑问**：推动继续阅读的问题，与单纯看不懂分开。
- **误解与歧义**：读者可能形成的错误心智模型，并标出触发句。
- **期待债务**：文本承诺了什么、何时承诺、是否结算或长期拖欠。
- **情绪脉冲**：好奇、紧张、爽、痛、暖、烦、麻木等发生在哪个动作或信息点。
- **阅读阻力**：回读、跳读、走神、弃读冲动及其直接原因。
- **翻页动力**：具体是哪一个未决行动、风险、选择或信息推动下一段。

不要把“作者想表达什么”写成第一遍结论。区分“暂时未知但有吸引力”和“缺少必要信息导致无法理解”。

## 第二遍：对照作者意图

仅在完成第一遍记录后读取大纲、设定、追踪和作者说明，逐项分类：

1. **正文成立**：读者体验与意图一致。
2. **正文缺失**：关键信息只存在于作者资料。
3. **投放过早**：读者在需要悬念前已能确定答案。
4. **投放过晚**：理解当前行动所需的信息尚未出现。
5. **信号过弱或过强**：线索存在，但普通读者难以接住或几乎等于明示。
6. **有益误导**：误解可被后文公平纠正并增强体验。
7. **破坏性误导**：误解来自表达缺陷、视角作弊或因果缺口。

修订落到“补哪条可见信息、移动哪个信号、删哪句提前解释”，优先最小改动。若修改会改变事实、伏笔、人物状态或章节承接，交回 `story-long-write` / `story-short-write` 执行并同步追踪；只有不同方案会导向不同正典时才请求裁决。

## 与 oh-story-claudecode 配合

具体路由、前后置关系和降级规则见 `references/oh-story-integration.md`。核心边界：

- 上游 `story-long-write` / `story-short-write` 负责创作与追踪；本 skill 在成稿后以隔离视角检查读者体验。
- 上游 `story-review` 可读取全部项目资料做综合审查；本 skill 的第一遍故意不读取这些资料。
- 上游 `story-long-analyze` / `story-short-analyze` 拆解其他作品；本 skill 不做市场样本拆解。
- 发现结构问题时输出证据和修订目标，再交给上游写作或审查 skill，不直接维护上游派生追踪文件。

## 交付

按 `references/cold-read-ledger.md` 输出：范围与污染声明、逐段体验账本、读者心智模型、最大弃读点、最强翻页点、期待债务表、第二遍意图偏差、最小修订清单。

每个判断必须绑定章节、场景或短引文。不得声称代表所有读者；结论是一次受控读者模拟，应在读者样本或真实反馈出现后复核。

## 七猫开篇漏斗检查

目标平台明确为七猫且范围包含首章或黄金三章时，第一遍冷读完成后运行 `scripts/simulate_qimao_funnel.py`，把前 500 可见字符与各章末 200 字作为固定取证窗口；数字是可复查的观察点，不是平台公布阈值，也不预测真实完读率或次留。

- 前置窗口判断核心危机、独特承诺或人物当前问题是否已经可感知；未出现记 `RISK`，不得仅凭字数“判死刑”。
- 每章尾段必须写出一个具体的下一步等待，并标记行动、风险、选择、信息、关系变化或兑现后果类型。说不出具体问题时记 `RISK`；只有项目明确启用七猫发布门禁，且章尾确实完成性收束、没有其他连续阅读动力时才记 `BLOCK`。
- 报告保存到 `报告/平台诊断/七猫开篇漏斗.md`，同时保留脚本 JSON 证据。修订章尾后重新提取，不允许用模型记忆沿用旧窗口。
