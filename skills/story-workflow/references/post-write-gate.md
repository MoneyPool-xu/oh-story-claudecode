# 自动写后门禁

## 写前自然成稿预防

每次新写、续写或重写正文前，在同一轮执行：

1. 读取当前细纲、上一章结尾、追踪状态、项目文风、本场角色声纹，以及本章直接相关的拆文报告/手法卡。
2. 调用 `story-natural-drafting`，按其固定模板生成《第XXX章自然成稿指令卡》；文件项目保存到 `{书目录}/报告/自然成稿/第XXX章_写作指令.md`。
3. 校验章卡：输入版本必须当前、必填字段必须完整、所有占位符必须替换，并明确本章唯一重心、笔墨轻重、拆文可迁移写法、长短句落点、基础背景禁写清单、新词白话解释、人物能力边界、关键物件状态、核心概念重复预算、危险余波和 AI 痕迹禁区。任一项失败即 `BLOCK`，不得生成正文。
4. 将完整章卡交给 `story-long-write` / `story-short-write`，不能缩成一句风格提示；由写作 skill 完成正文和正典追踪事务，章卡本身不写入正文。
5. 拆文只迁移句群节奏、信息延迟、悬念升级、对白功能和笔墨分配；不得复刻原句、专名、人物关系、罕见场景组合或情节节点顺序。没有手法输入时写“无对标输入”，不得假装已经学习。
6. 预防性控制不替代写后检查；不得为了“真人感”故意写错、写碎或删除动作主体。

## 默认门禁

每次新写、续写或重写正文后，在同一轮按顺序执行：

1. 完成写作 skill 自带的字数、格式、连续性、退化和 AI 模式检查。
2. 调用 `story-review` 的 lean 模式审查本轮变更范围；S1/S2 或等价阻断项交回写作 skill 修订。
3. 调用 `story-prose-style` 做写后文风反向审核：以项目文风、稳定样章和角色声纹为权威，检查正文是否发生 BREAK/DRIFT；确认成立且不改变正典的问题直接修复并复检。没有文风文件或稳定样章时标记 `NEEDS-BASELINE`，不得拿通用审美伪造通过。
4. 调用 `story-deslop` 处理确认存在的 AI 痕迹；除模板句、解释腔和电报体外，必须执行 Gate H，复核动作主体、物理状态、新词用途、行家能力、概念复读和危险余波。不为通过检测破坏人物声线、伏笔或题材节奏。
5. 调用 `story-chinese-proofreading` 做保守终校，只修明确语言错误。
5. 任一步修改正文后，重新执行受影响的后续步骤；最终只汇报当前版本结果。

## 条件门禁

- **文风基线补建**：没有项目文风文件或稳定样章时，写后反向审核只能记为 `NEEDS-BASELINE`；在获得样本或用户明确风格要求后，先建立基线再重跑，不把“没有依据”当作 PASS。
- **自然成稿复检**：用户指出平均用力、过度解释、人物同声、动作含混、假长句、连续单句段、行家失智、外行反教、谜底同义词复读、危险后反应过轻，或正文在写后发生大段重组时，重新运行 `story-natural-drafting` 的自然度门禁，再进入 `story-deslop`。
- **读者盲读**：首章、黄金三章结束、卷末、短篇完稿、简介定稿，或用户要求读者体验时运行 `story-reader-cold-read`。普通日更章节不默认盲读。
- **七猫开篇漏斗**：目标平台为七猫且本轮覆盖首章/黄金三章时，冷读后运行其漏斗证据提取，检查前置承诺可见性与各章末具体下一问。500/200 字是统一观察窗口，不是官方完读率阈值；报告不得伪造跳出率或次留预测。
- **原创性审计**：本轮使用了对标原文、拆文库、改编源、同人原作或其他明确参考来源时，运行 `story-originality-audit`；七猫发布门禁发现 `对标/` 时不得跳过。没有可比较来源时只登记来源并记 `NEEDS-DATA`，不给绝对原创结论或虚构固定百分比安全线。
- **番茄合规**：目标平台为番茄，且本轮内容准备发布、用户要求发布检查或作品达到发布节点时，运行 `story-fanqie-compliance`。普通草稿不默认运行平台门禁。
- **数据诊断**：仅在作品已发布且提供真实指标定义、样本和时间范围时运行 `story-serial-performance-diagnostics`。
- **编辑反馈闭环**：用户提供平台退稿原话时，按 `story-review` 的 `references/editor-feedback-loop.md` 保存原始样本、复现正文证据并生成本书规则；单次反馈不得自动修改全局 Skill。

## 停止与跳过

- 用户明确说“只写正文”“跳过写后检查”或点名跳过某项时，遵从并在交付中列出未运行门禁。
- 门禁发现需要改变核心设定、人物动机、结局或大范围正文时，先报告并等待用户决定。
- 所需 skill 不可用时标记 `UNAVAILABLE`，执行能力表中的降级方案；不得声称已调用。
- `story-natural-drafting` 不可用时，由写作 skill 按能力表和章卡固定模板内联生成完整的每章写作指令卡，执行场景重心、信息取舍、动作清楚度和自然句群检查，并在交接单标明降级；不可因 skill 不可用而跳过章卡门禁。

## 完成汇报

用一行汇总：`写作范围｜已运行门禁｜自动修订｜仍需用户决定｜跳过/不可用项`。只有默认门禁对当前版本无阻断项时，才能称本轮正文完成。
