# 普通读者清楚度与真人因果门禁

本门禁用于防止一种常见的二次 AI 痕迹：句子看似神秘、精炼或高级，普通读者却不知道谁在动、人物为何这样做，或人物经历重伤后立刻恢复。检查目标不是把所有秘密讲透，而是把眼前画面和人物反应写实。

## 一、十二类规则

| 类型 | 高风险表现 | 硬性修法 |
|---|---|---|
| 动作主体含混 | 同句出现人、脚、鞋、影子，却只写“它被拖走” | 重复具体名词，写清谁动、谁没动、谁受力 |
| 物理状态断线 | 上句鞋留在原地，下句鞋又跟人滑走；物件无交接换到另一人手里 | 写前列关键状态，场景转换后逐项核对位置、持有人和方向 |
| 假长句 | 把数个独立短句的句号换成逗号 | 只保留一个主干，其余内容必须与主干形成时间、条件、因果、转折或结果 |
| 新词无锚 | 甩出“香路、豁汤、牵影”等词，默认读者懂 | 第一次影响选择时，用一句白话说它是什么、拿来做什么或做错的后果 |
| 行家失智 | 看事人连续问本应自己断出的信息；郎中、船夫或家属反教行家本行禁忌 | 行家先交付专业判断；提问只用于来意、现实证据和能力边界外的事实 |
| 对话顺序颠倒 | 回答先于问题；人物无视刚发生的异变继续预设台词 | 每句必须回应上一句、现场变化或权力变化；删去可互换顺序的问答 |
| 原因被省没 | “他哭不出声”“她抬不起手”，但没有症状、受力或规则触发 | 幕后原因可留白，眼前症状必须可见；否则补触发或删戏剧化结果 |
| 余波过轻 | 差点死去的人下一句只“茫然睁眼”，随后正常行动 | 选择一两项具体后果，并让它妨碍下一步；不堆惊恐套餐 |
| 概念过曝 | 乳名、小名、幼名轮换出现，实质都在提醒同一谜底 | 合并为一个概念；每次重复必须增加证据、风险或选择，否则删除 |
| 镜像判词 | “洗的是泥，没洗掉去处”“挡的是门，没挡住魂” | 直接写残留物证、实际后果和人物下一步，不追求对仗金句 |
| 恐怖跳步 | 报告“鬼抓人”，直接跳到“人被救下” | 写出靠近、抵抗/误判、失效、后果四环；只给最强危险足够篇幅 |
| 反应平均化 | 所有人同时后退、尖叫、脸白、腿软 | 选与身份和位置有关的不同反应；次要旁观者不逐个领取反应句 |
| 行为常识 | 为凑“三次”写成“连着三日各砍一斧”，真实人物不会这样做 | 核对工序、频次、耗时、体力和现场目的；让重复来自真实阻碍 |
| 称谓失真 | 只因角色年轻或女性就称“姑娘”，忽略职业和权威身份 | 建立称谓表，按时代、关系、长幼、职业和权力统一使用 |

## 二、五秒理解检查

普通读者第一次读到一个动作或新词后，五秒内应能回答：

1. 谁或什么在动？
2. 往哪里动，什么东西没有动？
3. 人物现在要做什么？
4. 这一步有什么用，做错会怎样？
5. 眼前后果是什么？

“幕后是谁、为什么发生”可以继续悬置；以上五项不能靠读者回读设定补齐。

## 三、能力与提问边界

- 专家问“你们要看什么”是确认委托范围；专家问一连串基础事实再拼答案，是作者借角色递设定。项目若明确看事人能算出酒、债、伤、次数、方位等隐情，这些项目绝不能先问，必须主动断出后由当事人确认。
- 专家可主动断出能力范围内的隐情，再让当事人确认；涉及病因、命案、产权或公开定罪时，仍需郎中、尸格、契纸、口供等现实证据。
- 普通人可以提醒地方习惯或自己的经历，不能无来历地给专家下本行禁令。懂行配角若提出规则，要交代经验来源，并让主角判断是否适用。
- 专家也可以犯错，但错误必须来自规则例外、证据缺口、利益遮掩或明确偏见，不能为了制造反转临时降智。
- 专家说中私密事实后，让当事人、旧物或证据验证；不要再由专家解释别人为何不知道、为何忘了，替自己的高明辩护。

## 四、真正的中长句

长句不是字数达标，也不是把句号换成逗号。检查方法：

1. 圈出句子主干，确认只有一个观察或动作中心。
2. 给其余分句标注关系：何时、在什么条件下、为什么、发生了什么转折、造成什么结果。
3. 若每个分句都能独立交换顺序而意思不变，它们只是动作清单；重选观察中心或拆回自然中句。
4. 调查、空间关系、连续救援和因果适合中长句；惊点、不可逆选择和章尾新事实才适合短句。
5. 不设置平均句长、长句占比或机械长短交替指标，项目稳定样章和场景功能优先。

## 五、危险与余波

危险过程至少交付“威胁靠近—人物应对—应对失效或奏效—身体/物件后果”。救下人物以后，按危险强度选择具体余波：

- 轻度惊吓：说错话、抓住熟人、拒绝再靠近。
- 窒息、拖拽、撞击：咳吐、喘不上气、站不稳、重复摸伤处或确认影子/肢体。
- 濒死、附身、封闭空间：短时失语、认人延迟、失控躲避、无法继续原任务。

只选与本场后续行动有关的一两项。尖叫、流泪、发抖、失禁、后爬全部齐上，会变成另一种模板。

## 六、概念重复预算

写前把指向同一谜底的词并成一组，例如“乳名/小名/幼名/家中旧称”。正文每次使用前检查：

- 是否新增物证？
- 是否提高风险？
- 是否迫使人物选择？
- 是否改变读者对概念的理解？

四问全否就删。不要用同义词轮换规避重复，也不要把概念塞进每个人台词里提醒读者。
