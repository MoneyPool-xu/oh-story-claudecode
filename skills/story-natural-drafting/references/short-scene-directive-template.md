# 短篇逐节自然成稿指令卡

用于 `story-short-write` 的每个小节。短篇不套长篇章卡：先生成一张总卡，再在每节动笔前生成当前节简卡。

默认路径：

```text
{短篇目录}/报告/自然成稿/短篇总指令卡.md
{短篇目录}/报告/自然成稿/第NN节_写作指令.md
```

大纲、视角、平台、题材招式或项目文风改变后，受影响的卡标记 `STALE` 并重建。

## 短篇总指令卡

```markdown
# 短篇总指令卡
- 输入版本：设定={mtime/hash}；小节大纲={mtime/hash}；文风={mtime/hash/无}
- 目标平台：
- 核心读者契约：
- 核心支点与最终兑现：
- POV 及信息边界：
- 人物声纹：
- 题材招式（2-3 个）：
- 伏笔公平性与原创性禁区：
- 平台风险：
- 全篇禁止回退的 AI 模式：
```

## 第 NN 节写作指令卡

```markdown
# 第 NN 节写作指令卡
- 状态：CURRENT
- 来源行：小节大纲第 {行号} 行
- 当前读者问题：
- 视角人物眼前欲望：
- 主要阻碍与即时压力：
- 人物主动选择：
- 本节必须发生的状态变化：
- 新证据/局部支付：
- 本节结束后的读者问题；末节则写核心契约如何结清：
- 写足的核心画面：
- 压缩或禁写：
- 必须直说：动作主体、方向、即时后果、陌生词用途
- 可以留白：尚未揭晓的动机、身份、主题判断
- 句群与对白声纹：
- 平台约束：无；或番茄短篇风险摘要
- 原创性边界：只迁移功能，不复制表达、专名、关系映射、罕见桥段组合或节点顺序
```

## 放行规则

- 卡必须来自当前版本的 `设定.md` 与 `小节大纲.md`，不得拿上一节卡换节号复用。
- 欲望、阻碍、选择、变化不能全是抽象情绪词；至少落到一项具体行动或状态改变。
- 非末节必须说明读者问题怎样更新，不强制用悬崖式章尾；末节必须说明核心契约怎样结清。
- 若删去本节后全篇因果和读者理解均无损，停止起稿，回到 `story-short-write` 合并或重写大纲。
- 将完整总卡和当前节卡一起交给写作模型；正文中不得泄露卡片、指标或工程术语。
