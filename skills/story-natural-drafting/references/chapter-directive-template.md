# 每章自然成稿指令卡

本模板是写正文前的强制门禁。字段顺序固定，内容随章节变化；不能用上一章的卡只改章节号，也不能把模板原样留空后开始写作。

## 一、生成顺序

1. 读取对应细纲、上一章结尾、当前追踪、项目文风、主要角色声纹和本章相关拆文手法卡。
2. 先填写指令卡并校验；文件项目保存到 `{书目录}/报告/自然成稿/第XXX章_写作指令.md`。
3. 校验通过后，把整张指令卡交给 `story-long-write` / `story-short-write` 或实际写作模型。
4. 写作模型只输出正文，不把指令卡、分析过程或条目标题写入正文。
5. 正文完成后对照指令卡复读，再进入写后审查、去 AI 味和校对。

## 二、固定模板

```markdown
# 第XXX章自然成稿指令卡

## A. 版本与来源
- 状态：CURRENT
- 目标章节：
- 目标平台与读者门槛：
- 对应细纲：路径 + 修改时间/提交标识
- 上一章与追踪：路径 + 修改时间/提交标识
- 项目文风与角色声纹：路径 + 修改时间/提交标识
- 拆文手法输入：路径 + 修改时间/提交标识；没有则写“无对标输入”

## B. 本章唯一重心
- 一句话任务：
- 视角人物此刻最想得到什么：
- 主要压力：
- 必须做出的选择或行动：
- 本章必须交付的新事实/结果：
- 章末钩子：

## C. 笔墨轻重
- 写足（主要冲突、选择、异常或情绪后果）：
- 写到够用（现实证据、人物关系、环境支撑）：
- 一笔带过（转场、已知背景、重复反应）：
- 禁止平均分配篇幅：
- 本章最强危险的过程与事后余波：

## D. 拆文可迁移写法
- 本章采用的句群节奏：
- 本章采用的悬念/信息延迟方法：
- 本章采用的紧张升级或对白方法：
- 为什么适合本章：
- 原创性边界：不复刻原句、专名、人物关系、罕见场景组合、情节节点顺序

## E. 长短句与段落落点
- 使用自然中长句的区域及原因：
- 使用短句落锤的区域及原因：
- 允许一句一段的唯一位置：
- 常规段落如何组成完整句群：
- 禁止只改标点把短句粘成长句；禁止机械长短交替；禁止连续单句段和等长段落排队

## F. 信息取舍
- 必须直说：动作主体、方向、目标、先后、即时后果、陌生词用途
- 可以留白：
- 基础背景禁写清单（前文已建立、本章不得重讲）：
- 本章首次出现的新词/民俗及一句白话用途：
- 本章不能提前解释的答案：
- 核心概念及同义词重复预算：
- 关键人物/物件进入本章时的位置、持有人和状态：
- 反常结果必须让读者看到的触发或症状：
- 需要核对的现实工序、频次、耗时和称谓：

## G. 人物声纹
- 视角人物的观察偏向：
- 主要角色各自的说话目的、常用词与回避方式：
- 谁不能替作者解释设定或总结推理：
- 专业能力与知识边界：谁能主动判断什么、谁只能提供证据或地方经验：
- 本章行家必须主动断出、禁止询问的事实：
- 本章提问边界：哪些问题可以问，哪些信息应由行家主动断出：

## H. 本章 AI 痕迹禁区
- 禁止的项目旧病：
- 禁止连续同构句、机械对仗、镜像金句和“不是A而是B”式叙述翻转
- 禁止万能反应、无功能微动作、连续类比、段尾总结升华
- 禁止把所有背景、动机和规则一次解释完整
- 禁止行家失智递话、普通配角反教专家、谜底同义词轮换复读、危险后立刻复原
- 禁止故意写碎、写错或删掉动作主体来伪装真人

## I. 写作模型最终指令
（把下方固定指令中的方括号内容换成本章变量，不得留下占位符。）
```

## 三、交给写作模型的固定指令

```text
你现在只写《[书名]》第[XXX]章正文，严格执行本指令卡，不输出提纲、分析或写作说明。

1. 正典：以[对应细纲、追踪和设定]为事实边界，不擅自新增会改变后续的规则、身份、动机或结果。
2. 重心：本章只围绕[一句话任务]推进；[主要冲突/选择/异常]写足，[转场/已知背景/重复反应]压缩。
3. 文风：遵守[项目文风与角色声纹]；采用[拆文可迁移写法]的功能，但不得复刻参考原句、专名、人物关系、罕见场景组合或节点顺序。
4. 句法：在[中长句区域]用有明确主干的自然中长句串起动作、感知和因果；只在[短句落锤区域]使用短句。不得机械轮换长短句，不得只换标点粘句，不得连续用单句段制造紧张。
5. 信息：普通读者必须立即看懂谁在动、什么没动、往哪儿动、想做什么和眼前后果；[可以留白项]可以不解释，[必须直说项]不得含混。违反常理的结果必须给出可见触发或症状。
6. 背景：[基础背景禁写清单]不再重讲；新词只在第一次影响人物选择时，用一句白话说明它是什么、拿来做什么或做错的后果。
7. 对白与能力：每个人只为自己的目的说话，允许回避、抢话和说半句；禁止替作者复述设定、总结冲突或宣读完整推理链。项目规定行家能够判断的[主动断出清单]必须先由行家说出，禁止改成询问；普通配角不得无来源地反教行家本行规矩。
8. 去模板：避开连续同构句、机械对仗、镜像金句、叙述式“不是A而是B”、万能反应、无功能微动作、连续类比和段尾升华；同一谜底不得靠同义词轮换复读；危险后的反应必须与伤害强度相称；不要故意写碎、写错或删除动作主体。
9. 结尾：落在[章末动作/选择/物件变化/新事实]上，不总结本章意义。

写完后先在内部复读动作主体、笔墨轻重、句群自然度、角色声纹和基础背景重复；只输出修订后的连续正文。
```

## 四、开写前校验

以下任一项为“否”，状态改为 `BLOCK`，不得生成正文：

- 细纲、前章、追踪、文风和声纹的输入版本是否明确且仍为当前版本？
- 本章是否只有一个主要受力点，而不是把所有支线平均展开？
- 拆文写法是否写成可迁移功能，并标明来源与原创性边界？
- 长短句是否有场景落点，而不是平均句长、固定比例或交替模式？
- 是否列出已知基础背景，防止模型重新科普？
- 新词是否只做普通读者理解当前动作所需的白话解释？
- 是否核对人物能力、提问边界和关键物件状态，避免专家失智或物理断线？
- 是否明确列出行家必须主动断出、不得套问的事实？
- 是否核对现实行为、工序、时间频次和人物称谓？
- 是否给核心概念设置重复预算，并给最强危险安排相称的余波？
- 写作模型是否将收到整张指令卡，而不只是一句风格要求？
- 指令中是否已替换全部方括号占位符？

## 五、填写判断

### “按照拆文文风”如何落卡

不要写“模仿某书文风”。应拆成可执行功能，例如：

- 前两段先给具体危险，不先介绍地方沿革。
- 一次异常只升级一个认知层级，解释晚于人物选择。
- 连续动作以一个有主干的中长句串起，惊点另起短句。
- 对话先暴露利益和恐惧，规则只解释当场会害人的一步。

### “重点突出”如何落卡

可用“主要内容六至八成、支撑内容两至三成、转场最少”帮助取舍，但不得机械数段、数字数或字数。真正标准是：扩写人物必须承担的选择与后果，压缩不改变本章决定的材料。

### “省略基础背景”如何落卡

先列禁写清单，例如“主角是看事人”“无名魂不能入泰山”“上一章已经说明的叫魂规矩”。正文不再重新定义；只有规则在本章第一次造成新后果时，才由人物动作或一句白话补足差异。

### “长短句结合”如何落卡

按功能指定位置，不规定数量。追查、多人连续动作、空间关系和因果判断适合有清楚主干的中长句；危险真正落下、人物做出不可逆选择、章末新事实适合短句。短句不是默认恐怖感，中长句也不能变成逗号拖串。
