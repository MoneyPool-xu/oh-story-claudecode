# 番茄短篇适配：平台风险层

本文件只在目标平台明确为「番茄短篇」时加载。它负责调整信息排序、连载/阅读风险和交付检查，不替代人物因果、题材包、自然成稿或平台合规审查。

## 证据边界

- 番茄作家专区的现行发布规范、内容安全说明、低质内容治理公告，作为平台边界与风险证据。
- 番茄官方短故事课程、征稿与改编风向，只能形成带日期的 `Platform Observation`；跨多个时期、赛道和作品重复出现后，才能升为 `Platform Pattern`。
- 《怎样写好一篇短篇小说？》等公开写作文章只作 craft observation。可吸收「欲望与障碍」「具体名词和动词」「伏笔可回溯」「意外但合乎逻辑」，不得冒充番茄官方要求。
- 不把未经官方证实的完读率阈值、固定字数、前三句、固定视角、每节必须反转等说法写成平台铁律。

## 番茄短篇的优先诊断

1. **承诺可见**：开篇是否尽早让读者感到本篇的核心困境、异常关系或独特卖点。不是必须在固定句数内交代全部设定。
2. **行动可见**：主角是否为了眼前欲望作出选择，而非长时间只承受、回忆或听别人说明。
3. **状态变化**：一场戏结束后，风险、关系、证据、资源、身份、决定、行动方向或读者判断是否至少有一项发生真实改变。
4. **局部支付**：核心兑现尚未来临时，是否持续给出新证据、小胜负、关系变化或代价；只有提问而无支付是高风险。
5. **理解负担**：人物、时间线、设定和专有名词是否先于当前人物问题大量进入。
6. **低质风险**：重复解释、同义复述、拼凑桥段、空转心理、无效微动作、批量模板段落是否稀释有效内容。
7. **结尾兑现**：末节首先结清本篇核心读者契约。开放余韵可以保留，但不能用未收主线冒充高级留白。

以上指标是诊断器，不是目标函数。修改时优先补人物动机、因果和可见后果，不为让所有指标变绿而硬塞冲突、金手指、实物收益或章尾悬念。

## 场景价值门禁

番茄短篇默认启用场景价值门禁。写每节前，用一句到两句回答：

| 维度 | 要回答的问题 |
|---|---|
| 当前欲望 | 视角人物眼下要办成什么？ |
| 主要阻碍 | 谁或什么阻止他，压力为何是现在？ |
| 主动选择 | 人物采取什么有代价的行动、拒绝或判断？ |
| 状态变化 | 本节结束后，什么已经不能原样退回？ |
| 读者更新 | 新证据怎样改变读者的问题或判断？ |
| 承接/结清 | 非末节凭什么继续；末节结清哪笔核心契约？ |

判定规则：

- 不要求每节六项都达到最高强度，也不要求每节都有金手指、反转、打脸、实物收益或 cliffhanger。
- 删除本节后，因果、关系、证据、风险、选择、兑现和读者理解均无损，判为 `BLOCK`，先合并、压缩或重写小节大纲。
- 过渡节可以通过决定落定、关系回落、证据核验、代价显现或读者模型更新取得价值；纯移动和重复回忆不能独立成节。
- 末节不检查“下一节钩子”，改查核心承诺是否兑现、关键后果是否落地。
