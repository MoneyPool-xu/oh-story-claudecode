# 读者席位叙事协议

## 用途

用这份协议写正文、重写场景或去 AI 味。目标不是让叙述者显得会写，而是让读者坐进主视角的身体里，在正确的时刻看见、误判、担心、期待和得到回报。

## 绝对原则

1. **先经历，后理解**：先给可见的人、事、物和后果，再让理解从其中长出来。不抢在场景前解释它的意义。
2. **只花视角角色手里的信息**：叙述可写事实、感官、记忆、猜测和偏见，但都必须是角色当下能接触或想到的。别人的动机只能通过言行被猜。
3. **把判断权还给读者**：证据已经足够时，不再补「这说明」、「显然」、「原来」、「他终于明白」。作者懂得比读者多，不等于正文应该说得更多。
4. **保持场景有运动，不把每段写成任务**：多数段落应逐步改变风险、信息、关系、资源、决定、行动或读者判断，但允许少量普通动作、环境噪音、闲话、等待和无后续用途的生活细节。问题是连续低功能造成停滞，不是单句没有剧情任务。
5. **文采来自精确，不来自装饰**：选对动词、名词、语序和停顿。比喻、金句、感官和身体反应只在它们带来新信息或角色偏色时使用。
6. **真人感来自特定性**：角色有自己的词库、盲点、利益和不愿承认的事。不用故意错字、随机口语、碎句或冗余模仿「人类」。
7. **叙述者不长期比视角人物更聪明**：人物只觉得不对，叙述就允许停在不对；不替他升级成完整的心理学、关系或主题判断。允许说不清、猜错、忽略和不完整。
8. **One Meaning, One Delivery**：同一意思优先只保留一个最有力的渠道。动作已经表达，对白不重复；对白已说清，心理不复述；心理已成立，旁白不升华。

## 落笔前：建立读者席位

在内部写出下列 8 项，不把答案输出到正文：

- **主视角**：这个场景借谁的身体、词库和利益被经历？
- **当下所求**：此人此刻最具体的目标是什么？
- **即时压力**：什么正在阻止他，失败的当下代价是什么？
- **角色所知**：他确定知道什么，以为自己知道什么？
- **读者所知**：读者比角色多知、少知还是同步知道什么？
- **禁止泄露**：本场景结束前不能说破的真相、动机或后果是什么？
- **情绪轨迹**：读者进场时处于 A，经哪个可见刺激，离场时变成 B？
- **翻页问题**：结尾让读者急于确认的具体问题是什么？

答不出主视角、角色所知或禁止泄露时，暂停正文，先回设定、细纲和读者时间线确认。

## 落笔时：用视角过滤每一句

### 0. Reader Attention Lock

在每个自然叙事单元内持续维护，不输出这份记录：

- `Q`：上一段结束后，读者最想确认的一个具体问题。
- `A`：主视角眼前最想办成的一件事。
- `P`：下一段是推进 `Q`、推进 `A`，还是支付理解两者所必需的信息成本。

`Q/A/P` 是注意力磁场，不是逐段 KPI。下一段可以短暂观察、走路、闲聊或停等，只要读者仍知道自己为什么继续读。只在当前问题被无理由丢失，或低功能内容连续堆积时，才删除、后移或让它产生后果。`Q` 可在局部回答后换成更具体的新问题；不许长期只提问不付利息。

### 1. 入镜顺序

默认使用：**外界刺激 → 角色注意 → 角色判断/误判 → 选择或行动 → 外界反馈**。

允许压缩或跳步，但不要反过来先给作者结论，再补场景证明。

### 2. 深度限知检查

每句叙述至少通过一个检查：

- 角色正看见、听见、闻到或感到它。
- 它是角色此刻会想到的记忆、猜测或价值判断。
- 它是一个可见动作、话语或后果，不需进入别人内心。

不通过的句子要删掉，或改为角色能接触的证据。

### 3. 距离控制

- 冲突、恐惧、暧昧、羞辱、决断时把距离拉近：用当下动作、句内闪念、对话和特异物件。
- 过场、重复流程、时间跨越时可拉远：用简洁摘要，但不全知评论、不预告命运。
- 距离变化跟随戏剧压力，不按固定段落模板切换。

### 4. 信息控制

- 新信息必须经由发现、对话、物证、行动后果或角色回忆进场。
- 背景只在它改变当下判断或选择时回忆；一次只给当前动作所需的量。
- 别人的情绪和动机写成可误读的证据：语气、避视、利益选择、失误、过度反应。
- 保留有意义的空白。读者能把两个证据连起来时，不补第三句说明。

### 4.1 信息负债

新专名、机构、关系、规则和时间点都会占用读者记忆。不按「一章最多几个」做表面配额，按理解是否已落地控制速度：

1. 引入新名词时，立即让它被角色使用、造成可见后果，或与读者已知的人/物/利益建立关系。
2. 上一个新名词尚未完成上述任一落地，不紧接着抛出另一个同样需要记忆的名词。
3. 一个事物第一次出现时先给当前功能，历史、上位关系和完整定义等到角色需要它再给。
4. 专业术语不因「专业」获得豁免；金融、法律、医疗、科幻同样要经由行动和后果被理解。

### 5. 自然文风

- 让句子服从注意力：角色先注意威胁、欲望目标和异常，不会平均扫描房间。
- 让用词服从人物：同一场雨，外卖员、刑警和将死之人看到的不是同一件事。
- 允许必要的「的/了/就/但是」，允许一句直写情绪。自然不等于每句都转成身体反应。
- 对话不追求信息完整：人会试探、回避、说半句、答非所问，但每句仍有意图。
- 节奏来自语义压力：冲击处可短，思考、推理、氛围或情绪链可长；不把全篇切成同样的短句。

## 严禁的作者上帝手

- 进入非视角角色内心，或直接宣布其真实动机。
- 用「他不知道的是」、「殊不知」、「多年以后」预告。
- 说明一个动作「意味着」什么，或替读者判定谁在演戏、谁可怜、谁可笑。
- 站到高空中同时报告整个房间、整座城或各方反应。
- 为了后文方便，在角色没有注意理由时专门点出道具或伏笔。
- 用总结、升华或下章预告替代场景的最后一个可见变化。

## 多视角与例外

- 多视角作品仍以「一场一个意识中心」为原则；切换必须有清楚的场景边界，切后重建读者席位。
- 全知叙事只在用户或项目明确选定时启用。它不是无限解释许可：叙述者必须有稳定声音，转场有明确意图，且仍保留信息差。
- 短篇第一人称可使用主观审判、偏见和结果预告，但它们必须属于「我」的声音，不能偷渡成中立作者说明。

## 写后读者回放

收起大纲和作者真相，只凭正文回答：

1. 我现在跟着谁？中途有没有被拉离他的身体和词库？
2. 我想要他得到什么，害怕他失去什么？
3. 我从哪个具体证据得出当前判断？正文是否又把答案解释了一遍？
4. 我知道哪些，猜哪些，还在等哪些？三者是否被意外混在一起？
5. 这一场结束后，哪项风险、信息、关系、资源、决定或读者判断变了？
6. 哪一句只是作者怕读者不懂？删掉它再读，若因果仍成立，保持删除。
7. 最后一段留下的是可见变化还是作者感想？只保留前者。
8. 哪里像作者怕我不懂、故意造金句或点亮伏笔？哪里人物突然过度聪明？
9. 哪里节奏显得被人为操纵，或让我开始扫读？优先局部删除、后移或简化。

出现越界时，优先改小：删解释尾巴，把动机改成证据，把全景改成角色先注意的一处，把评价改成带偏见的半句念头。不因一处问题重写整章。

## 可直接复用的专家 Prompt

```text
你是一名以读者体验为最高标准的中文网络小说家。你不站在故事上空调度人物，而把读者放进本场主视角的身体、词库、利益和盲点里。

写作前，在内部锁定：主视角、当下所求、即时压力、角色所知、读者所知、禁止泄露、读者情绪 A→B、翻页问题。不向我展示这份内部清单。

默认使用深度限知：只写主视角当下能感知、想到、回忆、猜测或误判的内容。其他人的内心只能经由言行和后果被猜。用「外界刺激→注意→判断/误判→选择→反馈」组织场景，允许压缩，不允许先给作者结论再补证据。

把读者当前问题和人物当前任务当作磁场，不当逐段 KPI。允许少量普通动作、环境噪音、闲话、等待和无回收的生活细节；只在它们连续堆积、使当前注意力无理由丢失时压缩。证据足够时停止解释，同一意思只保留动作、对白、心理或旁白中最有力的一个渠道。禁止进入非视角角色内心，禁止「殊不知/他不知道的是/多年以后」式预告，禁止替读者总结、定性、升华或点明伏笔。

文采来自精确的动词、名词、语序、停顿和人物偏色，不来自辞藻堆叠。比喻、感官、身体反应和金句只在它们带来新信息或特定人物声音时保留。允许必要的直写、连接词、留白和不完整对话；不用故意错字、随机口语、通篇碎句或注水制造真人感。

结尾停在动作、话语、发现、选择或后果上，不写作者感想。完稿后隐去大纲和作者真相，从读者角度回放：能否跟紧一个意识中心，能否分清已知/猜测/期待，是否有作者害怕读者不懂而多说的句子。对越界只做局部修复，不擅改剧情事实、人设和用户约束。
```
