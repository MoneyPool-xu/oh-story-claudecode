# Narrative Kernel：通用叙事内核

本文件只约束跨平台都成立的叙事因果。平台适配决定“什么时候给什么”，不能改写人物为什么行动，也不能规定正文句式。

## 八项内核

1. **人物当前目标**：主视角此刻具体要办成什么。
2. **读者当前问题**：读者正在等待哪个可说清的问题；普通伏笔不自动成为等待。
3. **POV 认知边界**：叙述只使用视角人物可感知、可推断的信息。
4. **因果与选择**：压力迫使人物选择，选择带来可见后果；巧合可以制造麻烦，不能代替解决。
5. **信息时机**：只在当前行动需要、读者即将误读或兑现需要时补信息。
6. **意义克制**：证据足够就停，不替读者总结，不在动作后补同义心理和金句。
7. **人物声线**：每个人按自身利益、知识、关系和说话习惯表达，不替作者说最聪明的话。
8. **自然节奏**：段落长短、展开密度由场景受力决定，允许普通句、过渡和生活噪音存在。

## 兑现而非计数

一次有效兑现至少能指出：先前许诺、压力来源、主角主动行为、可见结果和后续影响。狠话、脸色变化、旁观者震惊若没有改变身份、关系、资源、风险、目标或行动方向，只是伪兑现。

慢分两类：有效慢热让读者知道在等什么，并持续提供证据、部分支付或关系变化；无期待的慢只有回忆、环境和心情，不能说明它们如何服务当前问题。较长铺垫必须通过 **Attention Continuity**：删去这段后，读者对当前问题的等待、人物行动或必要理解是否受损？若都不受损，压缩或删除。

## 分层接口

- `narrative_kernel`：始终加载，不因平台更换而变化。
- `platform_constraints`：由目标平台 reference 生成的短卡，只调整卖点显现、信息排序、前期行动与兑现速度。
- `genre_prose_card`：题材边界与读者期待。
- `prose_kernel`：读者席位、人物声线、自然句法和去作者显形；优先于平台的表达偏好。

冲突时按：用户明确要求与项目事实 → Narrative Kernel → 题材契约 → 平台风险提示 →统计经验。平台要求不得制造人物降智、无因果打脸、短剧式对白或机械爆点。
